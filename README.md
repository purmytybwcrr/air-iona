## Overview

AIR Iona is a mono-synth with three oscillators, a sequencer, and a built-in 32-band vocoder that treats a carrier signal with a microphone or audio sidechain for classic robotic vocal effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AIR Iona** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Oscillators** | Three VA oscillators with saw, pulse, and FM modulation |
| **32-Band Vocoder** | Carrier-modulator vocoder with 32 analysis bands |
| **Step Sequencer** | 16-step note sequencer with accent, slide, and transpose |
| **Arp Mode** | Six-mode arpeggiator synced to host BPM with latch |
